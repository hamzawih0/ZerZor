# EXtZerzor 使用说明

## 这是什么

`EXtZerzor` 是一个浏览器扩展。

它的作用很简单：

- 帮你自动跑 OpenAI / Codex 的 OAuth 注册流程
- 自动取邮箱
- 自动收验证码
- 自动继续后面的步骤

如果你只想知道怎么用，不想看原理，直接往下看就行。

---

## 先说最重要的

这个工具**不是装上就能直接跑**。

你至少要先准备好下面这些东西：

1. 一个可用的 `Microsoft Account Manager`
2. 这个服务对应的 `MAIL_API_TOKEN`
3. 一个可用的 OAuth 来源

OAuth 来源有两种：

- `CPA Auth`
- `Sub2API`

如果上面 3 个东西你都没有准备好，工具就会报错。

---

## 第一步：安装扩展

1. 打开浏览器地址栏，输入 `chrome://extensions/`
2. 打开右上角的“开发者模式”
3. 点击“加载已解压的扩展程序”
4. 选择当前项目文件夹
5. 加载完成后，打开这个扩展

如果你改了代码，看不到新效果：

1. 回到 `chrome://extensions/`
2. 找到 `EXtZerzor`
3. 点一下刷新按钮

---

## 第二步：你到底要准备什么

### 1. Microsoft Account Manager

你需要一个已经部署好的 `Microsoft Account Manager` 服务。

你要能拿到：

- 服务地址
- `MAIL_API_TOKEN`
- 收码模式

收码模式一般是：

- `graph`
- `imap`

你填什么，就要和你服务端实际配置一致。

### 2. OAuth 来源

你必须二选一：

- `CPA Auth`
- `Sub2API`

你没有可用的 OAuth 来源，就没法跑。

---

## 第三步：面板每一组怎么填

现在面板里已经分成几组了。

哪里显示“待填写”，就说明那里还没填完整。

### 一、OAuth 配置

这里是最先要填的。

#### 如果你用 `CPA Auth`

要填：

- `OAuth`
  这里选 `CPA Auth`
- `CPA Auth`
  这里填管理页地址

示例：

```txt
http://你的地址/management.html#/oauth
```

- `CPA Key`
  如果你有明文的管理 Key，就填进去

注意：

- 这里要填**明文 Key**
- 不要填加密后的字符串
- 如果你没有 `CPA Key`，有些流程也许还能跑，但稳定性不一定好

#### 如果你用 `Sub2API`

要填：

- `OAuth`
  这里选 `Sub2API`
- `Sub2API`
  这里填根地址

示例：

```txt
https://你的域名
```

- `API Key`
  如果你的后端开了鉴权，就填
  没开就可以先留空

注意：

- 不要填后台页面地址
- 只填根地址就行

### 二、验证源配置

这里一般必须填完整，不然大概率直接报错。

要填：

- `MSMgr`
  填 Microsoft Account Manager 的地址
- `Token`
  填 `MAIL_API_TOKEN`
- `Mode`
  选和服务端一致的模式

可选项：

- `Filter`
  关键词筛选，不懂就先留空
- `Alias Pool`
  想让自动取号时用别名邮箱，就勾上
- `Blocked Handling`
  想碰到封号时直接删掉账号就勾上
  不想删就不要勾

### 三、账号输入

这一组不一定要先手填。

#### `Email`

两种用法：

- 点 `Auto`
  自动从账号池里拿邮箱
- 手动粘贴
  自己填一个邮箱

#### `Password`

两种用法：

- 留空
  工具自动生成密码
- 手动填写
  你自己指定密码

如果你不知道填什么，`Password` 直接留空就行。

### 四、运行链接

这一组一般不用手动填。

这里只是给你看：

- 当前生成的 OAuth 链接
- 当前拿到的 Callback 链接

---

## 第四步：怎么开始跑

1. 先把“待填写”的组都填到不报错
2. 看右上角下面的数字框
3. 数字代表要跑几次
4. 填好次数后，点左边的播放按钮

如果你只是想先测试：

- 建议先填 `1`

这样最安全，也最容易看出哪里出错。

---

## 第五步：运行时会发生什么

工具会按步骤往下跑。

大致流程是：

1. 获取 OAuth 链接
2. 打开注册页
3. 填邮箱和密码
4. 收验证码
5. 填名字和生日
6. 自动确认 OAuth
7. 导入结果

你点播放后，会弹出运行窗口。

运行窗口里会看到：

- 工作流步骤
- 控制台日志
- 顶部停止按钮

---

## 第六步：怎么停止

想停止时，点停止按钮就行。

停止按钮有两个地方：

- 页面主区域的停止按钮
- 运行窗口顶部的停止按钮

它们的作用是一样的：

- 停掉当前运行
- 停止继续往后跑

---

## 最简单的推荐填写方式

如果你完全不知道怎么填，先按这个最简单方案来：

1. `OAuth` 选你手里有的那个
2. 把对应地址填上
3. `MSMgr` 填你的 Manager 地址
4. `Token` 填 `MAIL_API_TOKEN`
5. `Mode` 选对
6. `Email` 先点 `Auto`
7. `Password` 留空
8. 次数填 `1`
9. 点播放

---

## 常见报错怎么查

### 1. 一点播放就失败

先检查：

- `OAuth` 来源有没有选对
- 对应地址有没有填
- `MSMgr` 有没有填
- `Token` 有没有填
- `Mode` 对不对

### 2. 收不到验证码

先检查：

- Manager 地址能不能打开
- `MAIL_API_TOKEN` 对不对
- `Mode` 和服务端是不是一致
- `Filter` 有没有把账号过滤掉

### 3. 自动取号失败

先检查：

- Manager 里到底有没有账号
- 这些账号是不是已经被标记不能用了
- 你有没有把 `Filter` 填错
- 你有没有关闭别名池但主邮箱又不够

### 4. OAuth 跳不过去

先检查：

- OAuth 来源地址是不是正确
- `CPA Key` 是不是填了错误内容
- `Sub2API` 根地址是不是错填成后台页面地址

### 5. 运行窗口有日志，但就是不成功

这时不要乱点。

请按这个顺序看：

1. 先看哪一步报错
2. 再看那一步前面的最后一条正常日志
3. 再回去检查那一步需要的字段

不要一上来全改，容易把问题越改越乱。

---

## 建议你这样用

- 第一次先跑 `1` 次
- 先把 `Filter` 留空
- 先把 `Password` 留空
- 先确认单次成功
- 单次成功后再加大次数

这是最不容易出问题的方式。

## 最后一句

如果你要的是“稳定能跑”，不要一开始就同时改很多项。

最好的办法是：

- 先跑 1 次
