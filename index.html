小白也能看懂的运行说明页

这个页面是给不会配环境的人看的。你只要照着下面一步一步做，就能把 OAuth 配置、验证源配置、邮箱来源 这些东西填好，然后把工具跑起来。

打开 README 打开扩展管理页 打开工具页面
先看结论： 想跑成功，你最少要准备 3 样东西： `OAuth 来源`、`Microsoft Account Manager`、`MAIL_API_TOKEN`。 没有这 3 个，点播放大概率直接失败。

一眼看懂：先做什么

如果你完全不懂，先按这个顺序来，不要跳步。

  1. 先在浏览器里加载扩展：`chrome://extensions/` → 开启开发者模式 → 加载当前项目。
  2. 准备好一个能收验证码邮件的邮箱来源，最好是你自己控制的邮箱或邮箱 API。
  3. 准备好一个可用的 `Microsoft Account Manager` 服务地址。
  4. 拿到这个服务对应的 `MAIL_API_TOKEN`。
  5. 打开工具页面，先填 `OAuth 配置`，再填 `验证源配置`。
  6. 次数先填 `1`，第一次不要多跑。
  7. 点播放按钮，观察运行窗口里的工作流和日志。

每一块到底填什么

1. OAuth 配置

  • `CPA Auth`：填管理页地址，比如 `http://你的地址/management.html#/oauth`
  • `CPA Key`：如果你有明文管理 Key，就填；没有可以先不填
  • `Sub2API`：只填根地址，比如 `https://你的域名`
  • `API Key`：后端开鉴权才填，没开先留空

2. 验证源配置

  • `MSMgr`：你的 Microsoft Account Manager 地址
  • `Token`：就是 `MAIL_API_TOKEN`
  • `Mode`：一般选 `graph` 或 `imap`，要和服务端一致
  • `Filter`：不懂就先留空

3. 账号输入

  • `Email`：可以点 `Auto` 自动取号，也可以自己粘贴
  • `Password`：留空就自动生成，自己有固定密码就手填

4. 开始运行

  • 次数先填 `1`
  • 第一次不要开很多次
  • 点播放后看日志，不要乱点其它设置

可用的收码 / 邮件平台

下面这些是官方或正规文档，适合你自己控制邮箱时收验证码邮件。 当前这个工具面板最终还是要填 `MSMgr + Token`， 所以这些平台更适合你自己做收码管道、转发层、或者兼容到你自己的 manager 服务。 不建议用来做来路不明的临时号、租号、滥用注册。

Microsoft Graph / Outlook

官方 适合 Outlook / Hotmail

如果你的验证码邮件走 Microsoft 邮箱，这是最正统的方案。

打开官方教程

官方 适合 Gmail

最常见的问题

一按播放就失败

通常是 `OAuth 配置` 或 `验证源配置` 没填完整。

收不到验证码

先查 `MSMgr` 地址、`MAIL_API_TOKEN`、`Mode`，这三个最常出错。

Auto 取号失败

说明账号池没可用邮箱，或者 `Filter` 把目标账号过滤掉了。

这页文档只帮你更快配好工具，不帮你绕过平台规则。请只用你自己控制的邮箱、账号和 API。
